=== BUILDER FIXUP SET (per dylib, header-only — NO text/code bytes touched) ===
  1. LC_SEGMENT_64.fileoff  := plane base + new_plane_off  (TEXT->text plane, DATA->data plane, LINK->link plane)
  2. LC_DYLD_INFO_ONLY {rebase,bind,weak_bind,lazy_bind,export}_off  += (link_new - link_old)
  3. LC_SYMTAB {symoff,stroff}  += (link_new - link_old)
  4. LC_DYSYMTAB {indirectsymoff,...}  += (link_new - link_old)
  5. LC_FUNCTION_STARTS / LC_DATA_IN_CODE dataoff  += (link_new - link_old)
  6. LC_CODE_SIGNATURE dropped (Darling doesn't enforce) or offset-fixed
  vmaddr/vmsize UNCHANGED => dladdr/dlsym/rebase/bind targets identical => IDENTITY PRESERVED
  DATA plane mapped MAP_PRIVATE (COW) per process; TEXT+LINKEDIT MAP_SHARED RO

=> VMA count: 2 dylibs x3 = 6 VMAs  ->  3 plane VMAs (TEXT/DATA/LINK). At 40 dylibs: 120 -> 3.
